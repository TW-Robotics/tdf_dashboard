# FANUC ER-4iA (Educational Cell)

Small 6-axis industrial robot, delivered as FANUC's plug-and-play training cell for schools and universities.

## Included teaching material

- Ready-to-run "Solitaire" demo using iRVision and DCS, with full source code
- Setup and calibration instructions for robot, iRVision and DCS
- Exercises for lessons
- ROBOGUIDE academic simulation software (desktop or server licence)

## Getting started

1. Plug in the cell (230 V), close the door, power on the controller.
2. Reset alarms on the iPendant.
3. Run the Solitaire demo to check robot, camera and gripper.
4. Teach your own programs in **T1** with the deadman switch; simulate first in ROBOGUIDE.

## Safety

- Robot only moves in AUTO with the door closed (door safety switch).
- DCS limits are part of the delivered setup. Do not change them without the lab responsible.

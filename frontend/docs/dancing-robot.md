# Dancing Robot Setup Guide

The Playtastic Dancing Robot is a bipedal humanoid toy robot kept on the SHELF in the Digital Factory Lab, used for demonstrations and outreach. It has no network or programming interface; this guide covers safe operation only.

> **Note:** Lab-specific values (IP, frames, credentials) below are defaults. Check them against the robot before use.

---

## 1. Robot Data & Network Addressing

| Parameter | Value |
| :--- | :--- |
| **Controller** | Built-in toy electronics |
| **Software** | Factory firmware (not programmable) |
| **Control** | Buttons / remote (verify) |
| **Payload / reach** | Not applicable |
| **Robot IP** | None |

---

## 2. Safety Checks

> **Warning:** Use the robot only on the floor or the middle of a large table – it can walk off edges.

- Batteries inserted with correct polarity, battery cover closed.
- No damage to the housing.

---

## 3. Power-Up Procedure

### 3.1 Start the Controller
1. Insert batteries (type: see battery compartment).
2. Switch on.
3. Start a dance with the button or remote.

*Expected result: The robot plays music/lights and moves.*

## 6. Verification & Health Checks

Switch on and check that lights, sound and motion work.

---

## 7. Test Script

Not applicable – no programming interface.

*Expected behavior: Dance routine runs when started with the button/remote.*

---

## 8. Shutdown

1. Switch off.
2. Remove batteries if the robot will be stored for longer.
3. Release the robot on the Availability tab.

---

## 9. Troubleshooting

| Symptom | What to do |
| :--- | :--- |
| No reaction | Replace batteries; check polarity. |
| Remote does not work | Replace remote batteries; point directly at the robot. |
| Weak or slow movement | Batteries low – replace. |

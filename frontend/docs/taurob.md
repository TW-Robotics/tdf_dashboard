## Getting started

1. Read the prototype handover notes / project documentation first (location: _to be added_).
2. Check emergency stop and remote control function before every run.
3. Drive only in a cleared floor area, at reduced speed, with a second person present.

## Safety

- Tracked platforms can climb obstacles and tip over. Keep a safety distance.
- The arm is not collaborative. Do not enter its working range while it is powered.
